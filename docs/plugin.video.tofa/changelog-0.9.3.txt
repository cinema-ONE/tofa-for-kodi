- Report a problem now reaches the people who can fix it. The QR code under
  Settings -> Privacy & About opens this add-on's own issue tracker instead of
  tofa's support desk, which cannot act on a Kodi bug. Account and server
  trouble still goes to tofa, and the caption says which is which.
- A profile unlocked with a PIN no longer locks itself again while you are
  still watching. The unlock now extends as playback continues, so a long
  film no longer ends with the episode unticked and your place forgotten.
- Profile pictures now load however you are connected. Reached through tofa's
  relay rather than over your own network, every profile fell back to its
  initials; the artwork comes from your own server now, which works either
  way, and a picture changed on the web appears here without an update.
- Needs tofa server 0.9.30 or later. Older servers still work, and still say
  so once per Kodi session, but these two fixes are not there.
