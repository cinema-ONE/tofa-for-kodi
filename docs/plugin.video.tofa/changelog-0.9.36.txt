- More Like This no longer says "Nothing similar yet" the first time you
  open a title: it now waits a moment for your server to find related
  titles.
- Home responds to your remote sooner after it opens: a slow check of what
  your server supports no longer holds up Back, Select or switching
  sections.
- "Plays as" on a title's page now follows how Kodi really picks the screen
  mode, so it no longer says 1080p for a 4K film that Kodi shows in 4K, such
  as one whose picture is a little smaller than full 4K. It also names the
  refresh rate when Kodi has no mode at the film's own rate.
